# Bootstrap Task 1

A simple landing page built with **Bootstrap 5**, featuring:

- Top navbar (About, Team, Pricing, Issues, Sign In)
- Hero section with two columns: text + "Get More" button | illustration
- Blue background shape behind the white card
- Bottom section with 3 steps (Step 1, 2, 3)

## Tech Stack
- HTML5
- Bootstrap 5.3.8 (via CDN)
- Custom CSS (for the blue background shape)

## How to Run
1. Open `index.html` directly in your browser
   or
2. Use the **Live Server** extension in VS Code
